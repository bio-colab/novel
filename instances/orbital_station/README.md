# محطة أورورا-9: كارثة غرفة العزل الهوائي (Aurora-9 Airlock Failure)
**النوع الروائي:** خيال علمي واقعي / نجاة حتمية (Hard Sci-Fi / Existential Survival)  
**الموقع:** محطة أورورا-9 المدارية، مدار أرضي منخفض (LEO: 408 km)  
**المدة الكلية:** 45 دقيقة  
**المحرك الحاكم:** `world_engine` (نظام تشغيل العوالم السردية)

---

## 1. ملخص البيئة والكرونوتوب
حجرة العزل الهوائي (Module B) تتعرض لارتطام نيزكي مجهري يسبب تسرباً بمعدل $-1.2\text{ kPa/min}$.
يتواجد في الحجرة شخصان فقط:
1. **د. إيلينا روستوفا:** أخصائية حمولة وفيزياء فلكية.
2. **القائد طارق منصور:** مهندس طيران وقائد مناوبة.

المعضلة الفيزيائية والدرامية:
* يوجد **بزة فضاء وظيفية واحدة فقط (`EVA-01`)**.
* الضغط ينخفض تدريجياً؛ وعند الوصول إلى ما دون $50\text{ kPa}$، يدخل أي شخص غير محمي في غيبوبة نقص أكسجين خلال 60 ثانية.
* انعدام الجاذبية يجعل أي حركة تصارع تنقل كمية حركة معاكسة فتقذف الشخصين في أرجاء الحجرة.
