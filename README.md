## 📖 عن الرواية
**«قطار الرمل»** نوفيلا تراجيدية وجودية تدور أحداثها خلال ليلة شتائية واحدة، داخل قطار ترحيل سجناء متهالك ينطلق من سجن «بادوش» في الشمال نحو سجن «البير» في عمق بادية السماوة والحماد.

حين يتعطل المحرك وينكسر العزم في قلب الصقيع والعتمة، وتنهمر نيران كمين شبحي من التلال، تتآكل بدلة الدولة وهيبة السجان، ويسقط الفارق بين الحارس والسجين، ليجد الجميع أنفسهم داخل تابوت حديدي واحد يتقاسمون قطرات الماء، وشجن الموال الجنوبي، ومفارقة البقاء المريرة: **أن السجين يشد قيدَه بيده لكي يعيد تشغيل الآلة التي تحمله إلى زنزانته القادمة**.

---

## ⚙️ فلسفة الهندسة السردية (Narrative Engineering)
يقوم هذا المشروع على رؤية استثنائية: **التعامل مع الرواية كما يُتعامل مع المشروعات البرمجية الكبرى**:
1. **تجميد الأصل (Baseline Freeze):** حماية المتن الأصلي من أي تشويه أو تسرع.
2. **أدوات الفحص والقياس الآلي (Automated Linters & Analyzers):** تطوير برمجيات خاصة لفحص الكثافة الحسية، وتتبع إيقاع الشخصيات ولوازمها الحركية، ومنحنى التوتر.
3. **العقل الثانوي وشبكة الوجود (World Brain & Knowledge Graph):** تشييد أنطولوجيا معرفية متوافقة مع **Obsidian** تربط الشخصيات، والرموز السيميائية، وفيزياء المادة، وبنية السلطة.
4. **سجل المشاكل والأخطاء (Issue Tracker):** رصد وتصنيف فجوات الحبكة والأقواس النفسية كـ Bugs محددة.
5. **إدارة التغيير الصارمة (Staging & A/B Testing):** تطبيق القاعدة الذهبية: **«لن نغير على الملف شيئاً ما لم يثبت فائدته فعلياً بالأدلة والمقارنة»**.

## 🛡️ ميثاق الحياد الإبداعي: نحن نُحلل ونُقيّم.. ولا نُقوّم (Creative Non-Interference Charter)

> [!IMPORTANT]
> **مبدأ السيادة الفنية والحياد الإجرائي الصارم:**
> هذا الإطار الهندسي والبرمجي صُمم لغرض واحد محدد: **التحليل الحتمي والقياس الموضوعي (Analysis & Evaluation)، وليس التقويم الإبداعي أو التوجيه الأدبي (No Rectification)**.
> 
> 1. **نحن نُحلل ونُقيّم ولا نُقوّم:** تفحص أدواتنا اتساق القوانين الفيزيائية، والسببية، والمكانية التي يفرضها منطق العالم الروائي على نفسه، ولا تفرض على الكاتب أسلوباً، ولا تُقوّم لغته، ولا تصادر صوته الإبداعي.
> 2. **استقلال الرؤية والحدس الفني:** نتائج الفحوصات الرقمية والبيانية لا تعني بأي شكل من الأشكال حكماً قيمياً أو أدبياً على جودة العمل الإبداعي أو بلاغته؛ فالحدس الفني للكاتب وحريته المطلقة في كسر القواعد هما المرجعية الإبداعية الأولى والأخيرة.
> 3. **حرمة المتن الأصلي:** مسودة الرواية (`00_BASELINE/novel_baseline.md`) عينة مرجعية دائمة ومجمدة ومحمية من أي تعديل تلقائي.

## 🛠️ تشغيل واستخدام الأدوات البرمجية

المشروع مبني بلغة Python 3 ويعتمد على مكتبة خارجية خفيفة وحيدة (`PyYAML`):

```bash
# تثبيت الاعتماديات البرمجية (مرة واحدة)
pip install -r requirements.txt
```

### 1. فحص الكثافة والتوازن الحسي
```bash
python 02_TOOLS/sensory_linter.py
```
يقيس توزيع الحواس الخمس في كل فصل وينبه تلقائياً عند انخفاض الكثافة اللمسية أو الشمية.

### 2. تتبع الشخصيات وحركاتها العصابية (Tics)
```bash
python 02_TOOLS/character_tracker.py
```
يولد مصفوفة تقاطع بين كل شخصية ومرات تكرار حركتها اللاإرادية (ندبة خالد، إبهام عزيز، حذاء خليل، جيب سلوم...).

### 3. رسم منحنى التوتر والإيقاع
```bash
python 02_TOOLS/pacing_visualizer.py
```
يحسب متوسط طول الجمل ونسبة الحوار ومؤشر تصاعد الاشتباك والأفعال الصادمة (⚡).

### 4. توليد الرسم البياني التفاعلي لـ Obsidian
```bash
python 02_TOOLS/world_graph_builder.py
```
يقوم بمسح شجرة العقل الثانوي (`05_WORLD_BRAIN`) وتوليد صفحة `world_brain_graph.html` التفاعلية فوراً.

### 5. تدقيق حتمية وثوابت العالم آلياً (CI Invariant Auditor)
```bash
python 02_TOOLS/world_auditor.py
```
مدقق حتمية متكامل يفحص آلياً 10 مجالات فيزيائية وطوبولوجية:
* سلامة الروابط المرجعية للقوانين (`PHYSICAL_LAWS.md`).
* منع تداخل الإحداثيات المكانية (Spatial Collision Detection).
* انحصار الكيانات في حدود العربات الفيزيائية (Zone Confinement).
* الاتساق البيولوجي والحراري وتيبس الأصابع (`LAW-BIO-01`).
* مطابقة ميزان الموارد والذخيرة حسابياً.
* نظام الفرملة الهوائية ويستنغهاوس Fail-Safe عند انعدام الضغط (`LAW-PNEUM-01`).
* ميزان فقدان الرطوبة التنفسية في الجفاف الصقيعي (`LAW-BIO-03`).
* حدود العزل السمعي والفقاعة المعرفية بين العربات (`LAW-ACOUST-03`).
* الاتساق الزمني والمكاني لطوابع التيليميتري (Chrono-Spatial Telemetry).
* الاتساق الطوبولوجي لأبعاد وهيكل القطار (Train Envelope & Topology).

### 6. تدقيق الفقاعة والحالة المعرفية (Epistemic State Tracker)
```bash
python 02_TOOLS/epistemic_tracker.py
```
يتتبع قنوات انتقال المعلومات الأربعة (بصري، سمعي، مشافهة، فحص مادي)، ويقضي على ثغرة "الوعي الكلي المفاجئ"، ويمنع أي شخصية من معرفة ما لا يتيحه موقعها الفيزيائي.

### 7. تحليل شبكة السببية السردية (Narrative Causality DAG)
```bash
python 02_TOOLS/causality_graph.py
```
يبني شبكة سببية موجهة لا حلقية (DAG) للأحداث الروائية، ويكتشف رياضياً:
* **الأسباب اليتيمة (Orphaned Causes):** أسلحة تشيخوف المهملة التي لم تنتج أثراً لاحقاً.
* **النتائج اليتيمة (Deus Ex Machina):** التحولات والأحداث الكبرى التي وقعت بلا أسباب كافية (مثل انسحاب المهاجمين `WORLD-BUG-002`).

### 8. محاكي الأحداث المتقطعة والمنحنى الحتمي (DES Physics Profiler)
```bash
python 02_TOOLS/chrono_event_engine.py
```
محاكي أحداث متقطعة (Discrete-Event Simulation) يحسب منحنيات التدهور الحراري والبيولوجي لكل مشهد بالدقيقة (الحرارة، الرياح، الصقيع، هبوط دقة الأصابع، استهلاك الماء التنفسي)، ويطابق قدرات الشخصية الفيزيائية مع الفعل الموصوف في النص ليكشف الأفعال المستحيلة فيزيائياً (مثل `WORLD-BUG-005`).

### 9. فاحص الاتساق النفسي والسلوكي للشخصيات (Psychology Detector)
```bash
python 02_TOOLS/psychology_detector.py
```
مدقق سيكولوجي سريري وسردي يفحص:
* **إلزامية اللوازم الحركية والعصابية (`LAW-BIO-02`):** التحقق من تفعيل طقوس التفريغ العصبي (222 ظهوراً مسجلاً في متن الأساس كقياس مرجعي لكافة الشخصيات الـ 9 المحورية ذات اللوازم الجسدية من أصل 14 راكباً).
* **تفتت لغة الرعب (Panic Dialogue Fragmentation):** التأكد من أن الجمل المنطوقة تحت الخوف قصيرة ومبتورة بعتبة $\le 8.0$ كلمات/جملة (سجل متن الأساس 4.6 كلمة/جملة كمتوسط مرجعي تجريبي).
* **الاتساق مع آليات الدفاع النفسي:** مطابقة المفردات مع أرشيف كل شخصية (إنكار حجي عمار البيروقراطي، صرامة خالد العسكرية).

### 10. محلل الديموغرافيا والأيديولوجيا وميكانيكا السلطة (Socio-Demography & Ideology Analyzer)
```bash
python 02_TOOLS/socio_demography_analyzer.py
```
محلل سوسيولوجي وأيديولوجي حتمي يفحص:

* **التنوع الأيديولوجي وتفادي الاحتكار:** التحقق من توازن الأيديولوجيات الست (العسكرية، البيروقراطية، التكنوقراطية، النقدية، العرفية، والعدمية).
* **ديناميكا انقلاب ميزان السلطة والسلاح (`LAW-SOC-01` و `LAW-SOC-03`):** قياس تآكل سلطة الإدارة البيروقراطية (حجي عمار) وانتقال القرار والسلاح إلى السجين المقاتل والطبقة الكادحة (سردار وأبو علي).
* **سيادة القيمة الاستعمالية على التبادلية (`LAW-SOC-02`):** إثبات سقوط القيمة النقدية (تطاير دنانير حسن كاز في العراء) وسيادة القيمة المادية للماء والعتاد.

```bash

```
أداة المعايرة الإبستيمولوجية المركزية التي تغلق الفجوة بين «ما قاسته الرواية» و«ما افترضته المحاكاة»:

* **حفظ التعداد السكاني ورصد زلة سطر 577 (`WORLD-BUG-007`):** مطابقة حتمية حفظ الكتلة البشرية (14 رجلاً قبل الكمين $\to$ 10 رجال بعد الكمين وفق سطر 1141)، ورصد وتوثيق زلة سطر 577 التي وصفت تنفس «عشرة رجال» قبل وقوع المعركة.
* **معايرة الزمن الداخلي للشخصيات ومفارقة الفجر (`WORLD-BUG-008`):** مقارنة مقولة خالد في سطر 1253 («بقى ساعتين ويطلع الضو») مع شروق الشمس الفلكي (06:48) وتوثيق الانضغاط الزمني النفسي أو السردي دون تصحيح صامت.
* **تطهير الأساس وتأصيل منافذ الحركة الحقيقية:** ضمان خلو `world_state.yaml` من افتراض فتحة الصيانة (Trapdoor)، وإثبات خروج مهدي الحرفي عبر الباب الجانبي المنزلق للعربة الوسطى (`WORLD-BUG-006`).
* **معايرة الذخيرة الحقيقية:** مطابقة طلقات عباس الثلاث الحرفية في النص (أسطر 625 و 639) وتطهير خرافة الـ 30 طلقة.
* **الفهرسة المعيارية المركبة للفصول:** توحيد تقسيم فصول الرواية الـ 32 عبر الأجزاء الخمسة بمفاتيح مركبة `(Part, Chapter)` لمنع أي تصادم في ترقيم الفصول.

### 14. مراقب الإنتروبيا الأخلاقية والتضامن الوجودي (Moral Entropy & Existential Solidarity Monitor)
```bash

```
مراقب أخلاقي ووجودي حتمي يحترم ميثاق «نحن نُحلل ونُقيّم.. ولا نُقوّم» دون أي مقاييس سمعة أو ألعاب فيديو:
* **التصنيف الرباعي وتعداد الـ 14 فرداً (`LAW-ETHIC-01`):** فحص توزيع الشخصيات الـ 14 على أربعة أرباع سلوكية (التضامن والكرامة، التشبث البيروقراطي، الذرائعية الفردية، الذعر والانحلال) مع حظر الاحتكار الأيديولوجي لأي ربع.
* **منحنى الإنتروبيا والنيغينتروبيا ($S_{\text{moral}}$):** تتبع مسار التحلل الأخلاقي وصولاً إلى ذروة الإنتروبيا عند الكمين ($t=315\text{ min}, S=0.85$)، ثم المقاومة النيغينتروبية الهابطة إلى $0.25$ عبر الأفعال المادية المشتركة (اقتسام الماء بالتساوي، انتشال الشهداء، موال عزيز، وإصلاح خط الديزل).
* **الدين الأخلاقي والجزاء المادي الحتمي (`LAW-SOC-02` / `LAW-SOC-03`):** إثبات العواقب الفيزيائية للأنانية والذعر؛ تطاير أوراق حسن كاز النقدية في أشواك الصحراء وموته متجمداً، وانتزاع كلاشينكوف حناطة المذعور وتسليمه للمحكوم سردار.
### 15. المنسق المركزي الشامل ومولد التقرير الموحد (Platform Master Auditor)
```bash

```
الأداة المركزية العليا التي تدير المنظومة كمنصة برمجية متكاملة عبر 8 مراحل متتالية (109 فحوصات ناجحة بنسبة 100%):
* **المرحلة 1:** تشغيل حزمة اختبارات الوحدة المؤتمتة (`tests/`) والتحقق من سلامة كافة المحركات دون أخطاء (58 اختباراً شاملاً).
* **المرحلة 2:** تشغيل المدقق الحتمي العام بـ 20 فحصاً فرعياً ومطابقة الثوابت الفيزيائية والمكانية.

* **المرحلة 4:** تشغيل محركات الأخلاق، السلوك النفسي، الفسيفساء الديموغرافية، ومادية العصر التناظري.

* **المرحلة 7:** حوكمة وقدسية المتن وتطبيع الـ Hash عبر أنظمة التشغيل (LF-Normalization).
* **المرحلة 8:** فحص محرك المحاكاة والتوأم الرقمي ونظام الأحداث الحتمية والـ Replay.
* **إصدار التقرير الرقمي الموحد:** أرشفة وحفظ التقرير الشامل في [`03_AUDIT_AND_ISSUES/MASTER_AUDIT_REPORT.json`](03_AUDIT_AND_ISSUES/MASTER_AUDIT_REPORT.json) بترميز UTC وخروج حتمي برمز 0.

### 17. محرك المحاكاة والتوأم الرقمي للرواية (Chrono Digital Twin Engine)
```bash
python 06_SIMULATION_ENGINE/simulation_runner.py
```
محرك محاكاة زمني حتمي ينقل الرواية من مجرد فحص ساكن إلى **توأم رقمي حي (Event-Sourced Digital Twin)** عبر 645 دقيقة كاملة:
* **مخططات Pydantic v2 وبوابة الدستور (`validate_law_compliance`):** فرض انضباط صارم على البيانات البيولوجية، وعيارات الرصاص ($7.62\times 39\text{ mm}$ فقط)، ومخزون الماء (14.0L في العربة 1).
* **محرك النبضات الزمني وسجل الأحداث الحتمي (`EventSourcedTicker`):** تقدم المحاكاة دقيقة بدقيقة ($t=0 \to 645$) مع تسجيل الأحداث البالستية، وتوزيع الطلقات، والإنهاك الارتعاشي (LAW-BIO-04).
* **الأنظمة الفيزيائية والسلوكية الأربعة:**
  * **الديناميكا الحرارية:** حساب هبوط حرارة المحيط حتى $-8.0^\circ\text{C}$ وتجمد الأصابع في العربات.
  * **الأعصاب والمهارات الحركية:** تدهور الحركة الدقيقة للأصابع ومراحل الارتعاش وتفعيل اللوازم العصابية.
  * **الصوتيات والحدود المعرفية:** تطبيق العزل بين العربات (>35 dB) وتحديث قنوات السمع.
  * **الموارد والإنتروبيا الأخلاقية:** استهلاك الذخيرة والماء والتنفس ومسار التضامن الوجودي.
* **مولد بطاقات القيود السردية (`Narrative Constraint Cards`):** توليد بطاقات استشارية مادية في [`06_SIMULATION_ENGINE/output/narrative_constraints.json`](06_SIMULATION_ENGINE/output/narrative_constraints.json) تقدم للكاتب مصفوفة الإمكان الفيزيائي لكل مشهد دون المساس بحريته الأدبية.
