## 📖 عن الرواية
**«قطار الرمل»** نوفيلا تراجيدية وجودية تدور أحداثها خلال ليلة شتائية واحدة، داخل قطار ترحيل سجناء متهالك ينطلق من سجن «بادوش» في الشمال نحو سجن «البير» في عمق بادية السماوة والحماد.

حين يتعطل المحرك وينكسر العزم في قلب الصقيع والعتمة، وتنهمر نيران كمين شبحي من التلال، تتآكل بدلة الدولة وهيبة السجان، ويسقط الفارق بين الحارس والسجين، ليجد الجميع أنفسهم داخل تابوت حديدي واحد يتقاسمون قطرات الماء، وشجن الموال الجنوبي، ومفارقة البقاء المريرة: **أن السجين يشد قيدَه بيده لكي يعيد تشغيل الآلة التي تحمله إلى زنزانته القادمة**.

---

## ⚙️ فلسفة الهندسة السردية (Narrative Engineering)
يقوم هذا المشروع على رؤية استثنائية: **التعامل مع الرواية كما يُتعامل مع المشروعات البرمجية الكبرى**:
1. **تجميد الأصل (Baseline Freeze):** حماية المتن الأصلي من أي تشويه أو تسرع.
2. **أدوات الفحص والقياس الآلي (Automated Linters & Analyzers):** تطوير برمجيات خاصة لفحص الكثافة الحسية، وتتبع إيقاع الشخصيات ولوازمها الحركية، ومنحنى التوتر.
3. **العقل الثانوي وشبكة الوجود (World Brain & Knowledge Graph):** تشييد أنطولوجيا معرفية متوافقة مع **Obsidian** تربط الشخصيات، والرموز السيميائية، وفيزياء المادة، وبنية السلطة.
4. **سجل المشاكل والأخطاء (Issue Tracker):** رصد وتصنيف فجوات الحبكة والأقواس النفسية كـ Bugs محددة.
5. **إدارة التغيير الصارمة (Staging & A/B Testing):** تطبيق القاعدة الذهبية: **«لن نغير على الملف شيئاً ما لم يثبت فائدته فعلياً بالأدلة والمقارنة»**.

## 🛠️ تشغيل واستخدام الأدوات البرمجية

المشروع مبني بلغة Python 3 ويعتمد على مكتبة معيارية وحيدة خفيفة (`PyYAML`):

```bash
# تثبيت الاعتماديات البرمجية (مرة واحدة)
pip install -r requirements.txt
```

### 1. فحص الكثافة والتوازن الحسي
```bash
python 02_TOOLS/sensory_linter.py
```
يقيس توزيع الحواس الخمس في كل فصل وينبه تلقائياً عند انخفاض الكثافة اللمسية أو الشمية.

### 2. تتبع الشخصيات وحركاتها العصابية (Tics)
```bash
python 02_TOOLS/character_tracker.py
```
يولد مصفوفة تقاطع بين كل شخصية ومرات تكرار حركتها اللاإرادية (ندبة خالد، إبهام عزيز، حذاء خليل، جيب سلوم...).

### 3. رسم منحنى التوتر والإيقاع
```bash
python 02_TOOLS/pacing_visualizer.py
```
يحسب متوسط طول الجمل ونسبة الحوار ومؤشر تصاعد الاشتباك والأفعال الصادمة (⚡).

### 4. توليد الرسم البياني التفاعلي لـ Obsidian
```bash
python 02_TOOLS/world_graph_builder.py
```
يقوم بمسح شجرة العقل الثانوي (`05_WORLD_BRAIN`) وتوليد صفحة `world_brain_graph.html` التفاعلية فوراً.

### 5. تدقيق حتمية وثوابت العالم آلياً (CI Invariant Auditor)
```bash
python 02_TOOLS/world_auditor.py
```
مدقق حتمية متكامل يفحص آلياً 10 مجالات فيزيائية وطوبولوجية:
* سلامة الروابط المرجعية للقوانين (`PHYSICAL_LAWS.md`).
* منع تداخل الإحداثيات المكانية (Spatial Collision Detection).
* انحصار الكيانات في حدود العربات الفيزيائية (Zone Confinement).
* الاتساق البيولوجي والحراري وتيبس الأصابع (`LAW-BIO-01`).
* مطابقة ميزان الموارد والذخيرة حسابياً.
* نظام الفرملة الهوائية ويستنغهاوس Fail-Safe عند انعدام الضغط (`LAW-PNEUM-01`).
* ميزان فقدان الرطوبة التنفسية في الجفاف الصقيعي (`LAW-BIO-03`).
* حدود العزل السمعي والفقاعة المعرفية بين العربات (`LAW-ACOUST-03`).
* الاتساق الزمني والمكاني لطوابع التيليميتري (Chrono-Spatial Telemetry).
* الاتساق الطوبولوجي لأبعاد وهيكل القطار (Train Envelope & Topology).

### 6. تدقيق الفقاعة والحالة المعرفية (Epistemic State Tracker)
```bash
python 02_TOOLS/epistemic_tracker.py
```
يتتبع قنوات انتقال المعلومات الأربعة (بصري، سمعي، مشافهة، فحص مادي)، ويقضي على ثغرة "الوعي الكلي المفاجئ"، ويمنع أي شخصية من معرفة ما لا يتيحه موقعها الفيزيائي.

### 7. تحليل شبكة السببية السردية (Narrative Causality DAG)
```bash
python 02_TOOLS/causality_graph.py
```
يبني شبكة سببية موجهة لا حلقية (DAG) للأحداث الروائية، ويكتشف رياضياً:
* **الأسباب اليتيمة (Orphaned Causes):** أسلحة تشيخوف المهملة التي لم تنتج أثراً لاحقاً.
* **النتائج اليتيمة (Deus Ex Machina):** التحولات والأحداث الكبرى التي وقعت بلا أسباب كافية (مثل انسحاب المهاجمين `WORLD-BUG-002`).

### 8. محاكي الأحداث المتقطعة والمنحنى الحتمي (DES Physics Profiler)
```bash
python 02_TOOLS/chrono_event_engine.py
```
محاكي أحداث متقطعة (Discrete-Event Simulation) يحسب منحنيات التدهور الحراري والبيولوجي لكل مشهد بالدقيقة (الحرارة، الرياح، الصقيع، هبوط دقة الأصابع، استهلاك الماء التنفسي)، ويطابق قدرات الشخصية الفيزيائية مع الفعل الموصوف في النص ليكشف الأفعال المستحيلة فيزيائياً (مثل `WORLD-BUG-005`).

### 9. فاحص الاتساق النفسي والسلوكي للشخصيات (Psychology Detector)
```bash
python 02_TOOLS/psychology_detector.py
```
مدقق سيكولوجي سريري وسردي يفحص:
* **إلزامية اللوازم الحركية والعصابية (`LAW-BIO-02`):** التحقق من تفعيل طقوس التفريغ العصبي (222 ظهوراً في النص لكافة الشخصيات الـ 9).
* **تفتت لغة الرعب (Panic Dialogue Fragmentation):** التأكد من أن الجمل المنطوقة تحت الخوف قصيرة ومبتورة (بمتوسط 4.6 كلمة/جملة).
* **الاتساق مع آليات الدفاع النفسي:** مطابقة المفردات مع أرشيف كل شخصية (إنكار حجي عمار البيروقراطي، صرامة خالد العسكرية).

### 10. محلل الديموغرافيا والأيديولوجيا وميكانيكا السلطة (Socio-Demography & Ideology Analyzer)
```bash
python 02_TOOLS/socio_demography_analyzer.py
```
محلل سوسيولوجي وأيديولوجي حتمي يفحص:
* **الفسيفساء الديموغرافية والطبقية (`LAW-DEMO-01`):** فحص تمثيل الشرائح السبع والمناطق الجغرافية الـ 13 والبصمات اللغوية (التركمانية، الكردية، الجنوبية، والبيروقراطية).
* **التنوع الأيديولوجي وتفادي الاحتكار:** التحقق من توازن الأيديولوجيات الست (العسكرية، البيروقراطية، التكنوقراطية، النقدية، العرفية، والعدمية).
* **ديناميكا انقلاب ميزان السلطة والسلاح (`LAW-SOC-01` و `LAW-SOC-03`):** قياس تآكل سلطة الإدارة البيروقراطية (حجي عمار) وانتقال القرار والسلاح إلى السجين المقاتل والطبقة الكادحة (سردار وأبو علي).
* **سيادة القيمة الاستعمالية على التبادلية (`LAW-SOC-02`):** إثبات سقوط القيمة النقدية (تطاير دنانير حسن كاز في العراء) وسيادة القيمة المادية للماء والعتاد.
